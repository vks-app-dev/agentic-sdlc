# UI and accessibility standards

<!-- Agentic SDLC default. Used only for work items with a user interface: the UX designer, coders and the UI tester. -->

- **Components:** reuse the project's design system and existing components before building new ones.
- **States:** every screen handles loading, empty, error and success states; long operations show progress.
- **Accessibility (WCAG 2.2 AA):** semantic HTML, labels on every input, keyboard reachable with a visible focus, colour contrast at least 4.5:1, text alternatives for images, no information by colour alone.
- **Forms:** validate as the user goes, show errors next to the field in plain words, keep what was typed.
- **Responsive:** works from 360px wide phones to large screens; no horizontal scrolling of the page.
- **Text:** plain, consistent wording; dates, numbers and currency formatted for the user's locale.
- **Performance:** no layout jumps; images sized; first useful content quickly.
